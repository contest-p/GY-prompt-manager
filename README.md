# 🎯 GY Prompt Manager

> AI 프롬프트를 효율적으로 관리하는 CLI 프로그램

터미널에서 실행하는 간단하고 강력한 프롬프트 관리 도구입니다.  
자주 사용하는 ChatGPT, Claude 프롬프트를 카테고리별로 정리하고,  
검색·즐겨찾기·조회수 추적까지 한 번에 관리하세요! ✨

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 📝 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 저장 |
| 📋 목록 보기 | 저장된 프롬프트 전체 조회 |
| 📂 카테고리별 조회 | 카테고리로 필터링 |
| 🔍 검색 | 제목/내용에서 키워드 검색 |
| 👁️ 상세보기 | 프롬프트 전체 내용 확인 (조회수 자동 증가) |
| ⭐ 즐겨찾기 | 자주 쓰는 프롬프트 표시 및 목록 |
| ✏️ 수정 | 저장된 프롬프트 편집 |
| 🗑️ 삭제 | 프롬프트 삭제 (확인 메시지 포함) |
| 💾 자동 저장 | JSON 파일로 데이터 영속화 |
| 📤 Markdown 내보내기 | .md 파일로 백업 |

---

## 🚀 시작하기

### 요구사항
- Python 3.8 이상

### 설치 및 실행

```bash
# 저장소 클론
git clone https://github.com/contest-p/GY-prompt-manager.git

# 폴더 이동
cd GY-prompt-manager

# 실행
python main.py
```

---

## 📖 사용법

프로그램을 실행하면 메뉴가 표시됩니다:

```
=== 🎯 프롬프트 관리 프로그램 ===
1. 프롬프트 추가
2. 프롬프트 목록 보기
3. 카테고리별 보기
4. 프롬프트 검색
5. 프롬프트 상세보기
6. 즐겨찾기 토글
7. 즐겨찾기 목록
8. Markdown 내보내기
9. 프롬프트 수정
10. 프롬프트 삭제
0. 종료
```

원하는 번호를 입력해 기능을 사용하세요!
